# 贵阳 12MW 绿色数据中心项目规划可行性总报告

**报告版本：** 最终版
**报告日期：** 2025年4月
**总顾问：** 绿色数据中心规划可行性总顾问

## 摘要

本报告针对位于贵阳、规划IT负载为12MW、目标PUE为1.25、绿电比例为30%的A级数据中心项目进行了全面的可行性分析。分析涵盖了场址环境、能源系统、制冷方案、财务经济性及潜在风险等多个维度。

**核心结论：项目具备“有条件可行”的可行性等级。**

项目在供电架构、制冷方案选择、财务预算控制及绿电消纳策略方面均表现出较高的成熟度和可行性。然而，在制冷方案的最终选择、环境指标的实际达成以及部分运营细节上存在显著的不一致性与潜在风险，需在后续阶段进行重点优化与明确。具体而言，用户指定的“冷板式液冷”方案在系统优化评分中并非最优选择，而系统推荐的“传统房间级CRAC(上送风)+热通道封闭”方案在PUE和WUE目标上存在挑战。因此，项目可行，但必须满足特定的优化条件。

### 1. 项目背景与目标约束

本项目旨在贵阳市建设一座大型A级数据中心，总规划IT负载为12MW，总建筑面积约18,000平方米。核心目标与约束如下：
- **IT负载：** 12,000 kW (12 MW)
- **机柜功率密度：** 10 kW/机架，属于中高密度场景。
- **机房等级：** A级（GB 50174-2017标准），要求最高等级的容错能力。
- **PUE目标：** ≤ 1.25，属于高效率数据中心水平。
- **绿电比例目标：** 30%（可再生能源使用比例）。
- **预算约束：** 15,000 万元（人民币）。

这些约束条件共同定义了项目的技术路线、投资规模和运营目标，是本报告所有分析的基准。

### 2. 场址与环境可行性

- **地理位置：** 贵阳。贵阳地处云贵高原，气候温和，年平均气温约15℃，夏季凉爽，冬季温和。这种气候条件对数据中心散热非常有利，可大幅延长自然冷却时间，降低制冷系统能耗，是实现低PUE目标的天然优势。
- **水资源：** 报告显示当地水资源指数（CWSI）为0.44，属于中度缺水地区。这意味着高水耗的冷却方案（如开式冷却塔）会受到限制，其WUE（水利用效率）得分会较低，这与优化结果中“冷板式液冷+开式冷却塔”方案因高WUE而被低分评价的情况相符。
- **环境可行性结论：** 贵阳的气候条件为项目提供了极佳的节能基础，但水资源约束要求项目必须采用节水型冷却技术。场址本身是高度可行的。

### 3. 能源系统与绿电消纳策略

- **供电方案：** 采用“A级-35 kV 供电一体化方案”，外部电源为两路独立的35kV电源，内部采用“主变N+1，配变2N”的高可靠性架构。此方案符合A级机房标准，设计合理，可靠性高。专家评估的预期可用性高达99.98%，年停机时间仅1.6小时，可靠性评分0.92，方案成熟可靠。
- **绿电消纳策略：**
    - **优化结果：** 为满足30%的绿电比例目标，优化算法给出了一个包含风电、光伏和储能的组合方案：
        - **风电容量：** 约4.87 MW
        - **光伏容量：** 约1.00 MW
        - **储能容量：** 20 MWh
    - **消纳分析：** 绿电系统总发电量（581.70 MWh）完全被数据中心消纳，弃电率为0，消纳策略非常高效。储能系统在此次168小时仿真中主要起到辅助作用（放电5.52 MWh），未进行充电，表明算法倾向于优先使用可再生能源。
    - **成本与预算：** 绿电系统总成本估算为8761.03万元，是项目最大的单项投资（占总投资的68%）。其中，储能成本高达5000万元，是绿电成本的主要构成。这表明，在当前成本结构下，通过自建绿电系统来实现30%的绿电比例，投资压力巨大。
- **能源系统可行性结论：** 供电方案成熟可靠，绿电消纳策略技术可行且高效。但自建绿电系统的经济性压力较大，是项目总投资的主要部分。建议后续评估购买绿证（REC）或签订长期购电协议（PPA）等方式的成本效益，以优化投资结构。

### 4. 制冷系统与能效路径

这是本报告发现的最大矛盾点，也是“有条件可行”结论的核心依据。

- **用户指定方案：** 用户明确要求采用“冷板式液冷”。
- **系统优化结果：** 经过多目标优化（综合考虑PUE、WUE、TCO、CUE、WHR），系统给出的**最终推荐方案**是“**传统房间级CRAC(上送风)+热通道封闭**”，得分为0.522，是所有方案中得分最低（即综合代价最小）的。而“冷板式液冷”相关的多个方案（如冷板式液冷+混合型干冷器、冷板式液冷+水侧自然冷却）得分均在0.87以上，远高于推荐方案，这意味着它们在当前权重体系下的综合代价更高。
- **方案性能对比：**
    - **推荐方案（传统CRAC上送风）：** 预测PUE为1.229，满足1.25的目标。但预测WUE为1.65，**超过了**用户设定的WUE限值1.6。在贵阳中度缺水的背景下，这是一个严重的环境风险。
    - **用户指定方案（冷板式液冷，以“冷板式液冷+混合型干冷器”为例）：** 预测PUE为1.2，WUE为0.5，性能指标远优于推荐方案。但其TCO（总拥有成本）得分较高（1.3 vs 0.65），意味着初始投资和运营成本更高。
- **能效路径矛盾分析：**
    - **权重设置问题：** 优化算法中，TCO的权重（0.4）远高于PUE（0.2）和WUE（0.33），导致算法倾向于选择初始投资更低的风冷方案，即使其能效和环境表现较差。
    - **用户需求与系统推荐的冲突：** 用户明确要求液冷，但系统基于经济性优先的权重，推荐了风冷方案。这构成了规划中的根本性矛盾。
- **制冷系统可行性结论：** 从技术角度，两种方案都可行。但从项目目标看，存在矛盾：
    1.  若采纳系统推荐方案，**WUE目标无法达成**，且与用户“液冷”的要求相悖。
    2.  若采纳用户指定的“冷板式液冷”方案，**PUE和WUE目标均可达成**，但**初始投资会显著增加**，可能导致预算超支或压缩其他系统投资。
    **此环节是项目“有条件可行”的关键条件：必须重新审视优化权重，在“经济性”和“环境/能效目标”之间找到平衡，并对制冷方案进行二次决策。**

### 5. 仿真结果解读与运行策略

- **绿电仿真：** 168小时的仿真结果表明，在特定的一周内，优化后的绿电系统（4.87MW风电+1MW光伏+20MWh储能）能够完全满足30%的绿电供应目标，且无弃电。这表明在理想天气条件下，该组合方案是有效的。
- **运行策略建议：**
    - **储能策略：** 仿真中储能未充电，表明算法策略是“削峰填谷”或“应急备用”。实际运行中，应制定更精细的充放电策略，如在电价低谷期充电、高峰期放电，以利用电价差套利，降低运营成本。
    - **负载协同：** 利用AI预测负载和可再生能源出力，实现负载的灵活调度。例如，在风电、光伏出力高峰时，可调度非关键计算任务运行，最大化绿电消纳。
    - **制冷协同：** 根据IT负载和室外环境温度，动态调节制冷系统运行参数。在自然冷却可用时，最大化利用，减少机械制冷能耗。

### 6. 财务可行性与投资回收

- **总投资概算：** 项目总资本支出（CAPEX）估算为12,883.03万元，低于15,000万元的预算约束，结余2,116.97万元。
- **成本构成：**
    - 绿电系统：8,761.03万元 (68%)
    - 供电系统：3,000.00万元 (23%)
    - 制冷系统：1,122.00万元 (9%)
- **财务指标分析：**
    - **单机架成本：** 10.74万元/机架，处于行业较低水平，成本控制良好。
    - **投资回报率（ROI）：** 专家评估为12%，低于行业平均水平（15-20%）。主要原因是运营成本（尤其是电费）占比高，以及收入假设可能偏保守。
    - **投资回收期：** 约8年，略长于行业推荐的5-7年。
- **财务可行性结论：** 项目总投资在预算范围内，成本控制有效。但ROI和回收期指标处于行业边缘，存在一定财务风险。提升盈利能力的关键在于降低运营成本（如通过更优的制冷方案降低PUE）和提高机柜出租率及收入。

### 9. 综合结论与建议

**综合结论：项目“有条件可行”。**

该项目在供电可靠性、财务预算控制、绿电消纳技术等方面表现优秀，具备成功实施的基础。然而，**制冷方案的最终选择**是决定项目成败的关键条件。当前规划中存在用户指定方案与系统优化方案之间的矛盾，且系统推荐方案存在WUE超标的环境风险。

**核心建议：**
1.  **立即启动制冷方案的二次决策流程。** 建议组织专项会议，将PUE和WUE目标的重要性提升至与经济性同等或更高的级别，重新进行多目标优化，并基于新的优化结果，对“冷板式液冷”和“传统房间级CRAC”方案进行全生命周期成本（TCO）的详细对比。
2.  **优先考虑“冷板式液冷”方案。** 从技术性能（PUE、WUE）和长期趋势来看，液冷是满足高密度、高效率数据中心需求的最佳路径，也更符合贵阳的水资源约束。尽管初始投资更高，但更低的运营成本和更优的环境表现，将提升项目的长期价值和合规性。
3.  **重新进行财务测算。** 一旦确定制冷方案，需立即更新CAPEX和OPEX估算，重新计算ROI和投资回收期，确保财务模型依然稳健。若选择液冷，需评估预算结余（2116.97万元）是否足以覆盖增加的投资，或是否需要调整预算分配。
4.  **明确环境目标优先级。** 在项目章程中明确WUE目标（例如≤1.6 L/kWh），并将其作为与PUE同等重要的KPI进行考核，避免在后续设计中被牺牲。
