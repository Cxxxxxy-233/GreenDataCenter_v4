## 4. 综合技术方案

### 4.1 供电方案 (A级可靠性)

- **方案名称:** A级-110 kV 供电一体化方案
- **外部电源:** 两路独立的 **110 kV** 工作电源，每路均可承担100%负荷。
- **冗余架构:** 主变压器采用 **N+1** 配置，配电变压器采用 **2N (互为备用)** 配置，确保单一组件故障不影响业务运行。
- **内部配电:** 采用 **380/220V 单母线分段** 接线，支持在线维护。
- **应急电源:** 柴油发电机仅用于保障消防、安防等保安负荷，IT负载由双路市电+UPS保障。
- **专家意见:** 此方案经电力可靠性专家评审，预期可用性可达 **99.98%**，年度计划外停机时间约 **1.6小时**，满足A级机房标准。

### 4.2 制冷方案 (高效节能)

- **方案名称:** 分离式热管系统+自然冷却
- **选择依据:** 经多目标优化算法（权重：WUE 0.33, PUE 0.2, CUE 0.2, TCO 0.13, WHR 0.13）综合评分，该方案在乌兰察布寒冷气候下得分最高 (0.512)，实现了能效、水效与成本的最佳平衡。
- **方案优势:**
    - **极低WUE:** 预测WUE为 **1.53 L/kWh**，远低于传统水冷方案，符合当地水资源保护政策。
    - **高效PUE:** 预测PUE为 **1.171**，优于设计目标。
    - **余热回收潜力:** 预计可回收 **23,595 kW** 的余热，可用于园区或周边区域供暖。
- **被否决方案:** 传统风冷方案因无法满足20kW/rack的高密度散热需求而被一票否决；冷板式液冷等方案因水耗或TCO过高而排名靠后。

### 4.3 绿色电力消纳方案

本项目采用 **“自发自用 + 市场采购”** 的混合模式实现92%的绿电目标。

| 绿电来源 | 占比 | 年消纳量 (MWh) | 策略说明 |
| :--- | :--- | :--- | :--- |
| **自建直连** | **30%** | 92,321.64 | 自建28.11 MW风电 + 2.37 MW光伏，通过专线直供数据中心，实现物理消纳。 |
| **绿电交易** | **49.6%** | 152,638.44 | 与乌兰察布及周边新能源场站签署中长期购电协议 (PPA)，购买其绿色电力。 |
| **绿证购买** | **12.4%** | 38,159.61 | 购买绿色电力证书 (GEC) 作为剩余绿电消费缺口的补充。 |
| **合计** | **92.0%** | **283,119.70** | |

**经济性分析：** 每年绿电采购总成本约 **515.15万元**，其中绿电交易成本 **457.92万元**，绿证成本 **57.24万元**。

## 综合技术方案深化

综合方案应把制冷、供电、绿电和运维监测视为一个系统，而不是三个孤立子方案。

| 系统 | 推荐配置 | 专业说明 |
| --- | --- | --- |
| 制冷系统 | 分离式热管系统+自然冷却 | 重点校核 PUE、WUE、余热回收和高密机柜适配能力。 |
| 供配电系统 | A级-110 kV 供电一体化方案 | 外部电压：110 kV；冗余等级需与机房等级一致。 |
| 绿电直连 | 30% | 直连比例应结合场址资源、并网条件和负荷曲线复核。 |
| 绿电采购补足 | 绿电交易+绿证补足 | 建议同步配置绿电交易、绿证和碳核算台账。 |
| 风光储容量 | 风电 28.11 MW；光伏 2.37 MWp；储能 3.60 MWh | 容量结果应在全年 8760h 负荷曲线上复核弃电、缺口和储能循环次数。 |
| 可运维性 | 建议建立能源管理系统 EMS + DCIM 联动 | 持续跟踪 PUE、绿电占比、碳排、储能 SOC 与关键设备健康状态。 |
