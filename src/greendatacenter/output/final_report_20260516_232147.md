## 2. 设计边界、依据与关键假设

本方案的设计基于以下核心边界与假设：

*   **供电架构：** 遵循GB 50174-2017《数据中心设计规范》A级标准，采用两路独立110kV高压电源进线，每路承担100%负荷。
*   **可靠性目标：** 对标Uptime Institute Tier III等级，允许任何单点故障（包括计划性维护）不影响IT负载运行，预期可用性≥99.982%。
*   **绿电消纳模式：** 采用“并网型绿电直连 + 市场化绿电交易 + 绿证补足”的混合模式。直连比例经优化确定为30%（自建28.28MW风电+2.41MW光伏），剩余62%通过绿电交易和绿证实现。
*   **冷却策略：** 基于环保优先原则，在20种可行冷却方案中，通过多目标优化（PUE、WUE、TCO、CUE、WHR）选出最优解。
*   **经济性假设：** 机柜月租金按2.5万元/柜估算，年运营成本（不含电力）约占初始投资的1.6%。绿电溢价按0.03元/kWh，绿证价格按0.015元/kWh计。

## 4. 综合技术方案

### 4.1 供电系统方案 (A级-110kV 供电一体化方案)

*   **外部电源：** 两路独立的110kV双重工作电源，每路均可承担100%总负荷。
*   **变配电架构：** 主变压器采用N+1冗余，配电变压器采用2N（互为备用）架构，消除单点故障。
*   **UPS系统：** 采用 **14台800kVA UPS，2N架构**（每路7台，总容量11,200kVA/10,080kW）。负载率降至80%，冗余度提升至37%，显著高于Tier III标准要求，确保极高的供电连续性。
*   **配电架构：** 主机房采用 **380/220V 双母线冗余接线**，与2N UPS架构完全匹配，配电可靠性达到0.9999以上。
*   **柴发系统：** 仅用于消防、安防等保安负荷，作为市电全失的最终保障。

### 4.2 冷却系统方案 (分离式热管系统+自然冷却)

*   **技术选型：** 经多目标优化算法（权重：WUE 0.33, PUE 0.2, CUE 0.2, TCO 0.13, WHR 0.13）评选，选定 **“分离式热管系统+自然冷却”** 方案。该方案在乌兰察布冷凉气候下，得分0.512，为20个可行方案中的最优解。
*   **核心性能：**
    *   **预估PUE：** **1.171**，优于1.22的目标值。
    *   **预估WUE：** **1.53**，低于1.6的限制值，节水效果显著。
    *   **冷却功耗：** 3,039.47 kW。
*   **余热回收：** 预计可回收 **23,595 kW** 余热，推荐用于园区供暖或预热新风系统，进一步提升能源综合利用效率。

### 4.3 绿电消纳与储能方案

*   **自建绿电：** 配置28.28 MW风电和2.41 MW光伏，通过30%的直连比例直接供给数据中心。
*   **储能系统：** 将储能容量从3.6 MWh翻倍至 **7.2 MWh**，提供约30分钟的缓冲时间。此举旨在平滑风光出力的间歇性，提升绿电消纳能力，并为电网波动提供毫秒级响应支撑。
*   **市场采购：** 剩余62%的绿电缺口，通过“绿电交易”（49.6%）和“绿证”（12.4%）组合方式补足，在控制成本的同时确保92%的绿电目标。

## 综合技术方案深化

综合方案应把制冷、供电、绿电和运维监测视为一个系统，而不是三个孤立子方案。

| 系统 | 推荐配置 | 专业说明 |
| --- | --- | --- |
| 制冷系统 | 分离式热管系统+自然冷却 | 重点校核 PUE、WUE、余热回收和高密机柜适配能力。 |
| 供配电系统 | A级-110 kV 供电一体化方案（修订版） | 外部电压：110 kV；冗余等级需与机房等级一致。 |
| 绿电直连 | 30% | 直连比例应结合场址资源、并网条件和负荷曲线复核。 |
| 绿电采购补足 | 绿电交易+绿证补足 | 建议同步配置绿电交易、绿证和碳核算台账。 |
| 风光储容量 | 风电 28.28 MW；光伏 2.41 MWp；储能 7.20 MWh | 容量结果应在全年 8760h 负荷曲线上复核弃电、缺口和储能循环次数。 |
| 可运维性 | 建议建立能源管理系统 EMS + DCIM 联动 | 持续跟踪 PUE、绿电占比、碳排、储能 SOC 与关键设备健康状态。 |
