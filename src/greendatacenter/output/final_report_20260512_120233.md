# 乌兰察布 500kW 绿色数据中心项目可行性评估报告

**报告编号:** GDC-2025-ULQ-001
**编制日期:** 2025年4月8日
**编制人:** 绿色数据中心规划可行性总顾问

## 摘要

本报告对在内蒙古乌兰察布市建设一座设计IT负载为500kW、绿电比例目标70%、预算2000万元人民币的A级绿色数据中心项目进行了全面的可行性评估。评估涵盖了场址环境、能源系统、制冷方案、财务经济性及潜在风险等多个维度。

**核心结论：本项目暂不可行。**

主要障碍在于**财务预算严重不足**。根据当前最优技术方案（绿电系统+制冷系统+供电系统）的估算，项目总投资高达约1.11亿元人民币，远超2000万元的预算上限，缺口超过9100万元。尽管项目在技术路径（如绿电消纳、制冷能效）上具备可行性，且乌兰察布地区拥有得天独厚的自然冷源和绿电资源，但巨大的资金缺口使得项目在当前预算约束下无法启动。

若项目方能够大幅增加预算（至1.1亿元以上）或显著调整技术方案（如大幅降低绿电比例、采用市电直供等），则项目具备“有条件可行”的基础。本报告将详细阐述各维度的分析结果，并为后续决策提供依据。

## 1. 项目背景与目标约束

本项目旨在乌兰察布市建设一座500kW IT负载、达到国家A级机房标准、PUE目标为1.3的绿色数据中心。项目核心约束如下：

- **地理位置:** 内蒙古乌兰察布市。该地区以其丰富的风能、太阳能资源以及年均气温低（约4.3℃）而闻名，是建设绿色数据中心的理想选址。
- **核心目标:**
    - **IT负载:** 500 kW
    - **绿电比例:** 70%
    - **PUE目标:** ≤ 1.3
    - **机房等级:** A级（容错级）
- **关键约束:**
    - **预算上限:** 2000万元人民币
    - **冷却技术:** 用户指定为“浸没式液冷”，但系统优化后选择了“传统房间级CRAC(上送风)+热通道封闭”。（**数据冲突/待补充**：用户需求与系统推荐方案存在矛盾，需用户确认最终冷却技术路线。）
- **财务假设:** 提供了分时电价体系，为运营成本分析提供了基础。

## 2. 场址与环境可行性

**结论：高度可行。** 乌兰察布是建设绿色数据中心的优选地。

- **气候优势:** 乌兰察布年均气温低，全年有长达8-10个月可利用自然冷源。这为降低制冷系统能耗、实现低PUE提供了天然优势。系统推荐的“传统房间级CRAC(上送风)+热通道封闭”方案，正是充分利用了当地的自然冷却潜力。
- **绿电资源:** 乌兰察布是国家重要的新能源基地，风电、光伏资源丰富且成本较低。这为实现70%以上的绿电比例提供了坚实的资源基础。
- **政策支持:** 内蒙古自治区及乌兰察布市对大数据、云计算产业有明确的政策扶持，包括电价优惠、土地供应、税收减免等，有利于降低项目建设和运营成本。
- **环境专家评估:** 环境专家给出了0.88的高分，认为项目在能效和碳减排方面表现优异，并建议进一步提升绿电比例至90%以上。

**关键指标：**
- 年均气温：约4.3℃（数据缺失/待补充，基于公开信息）
- 自然冷却可用时长：> 7000小时/年（估算）
- 环境专家评分：0.88/1.0

## 3. 能源系统与绿电消纳策略

**结论：技术方案可行，但成本高昂。** 系统优化结果展示了实现70%绿电比例的技术路径，但其成本是导致项目超预算的直接原因。

- **优化结果解读:**
    - **配置方案:** 优化算法建议配置 **1 MW 风电 + 1 MW 光伏 + 约 40 MWh 储能**。这是一个典型的“风光储”一体化方案，旨在通过储能平抑风光出力波动，实现高比例绿电供应。
    - **绿电供应率:** 优化结果显示绿电供应率可达 **100%**，远超70%的目标。但这是以**10%的弃电率**为代价，意味着部分可再生能源发电被浪费。
    - **电网购电:** 优化结果显示电网购电量几乎为0，意味着项目可以完全自给自足，脱离对传统电网的依赖。这在技术上极具前瞻性，但经济上代价巨大。
- **成本分析:**
    - 绿电系统总成本高达 **1.09亿元**，其中**储能系统**成本高达 **9889万元**，占总成本的绝大部分。储能的高昂成本是项目超预算的核心原因。
    - 风电和光伏的单位成本（700万元/MW 和 350万元/MW）处于行业合理区间，但为了满足高比例绿电和自给自足，所需的储能容量过大，导致经济性急剧下降。
- **供电系统:** 电力可靠性专家建议采用符合A级标准的 **2N UPS + 双路市电** 方案，总成本约125万元。该方案虽然可靠性高，但与绿电系统的“孤岛”运行模式存在理念冲突。**数据缺失/待补充**：绿电系统与市电系统的具体并网与切换逻辑未在数据中明确，这是影响可靠性和成本的关键点。

**关键指标：**
- 推荐风电容量：1 MW
- 推荐光伏容量：1 MW
- 推荐储能容量：40 MWh
- 绿电系统总成本：1.09亿元
- 供电系统成本：125万元

## 4. 制冷系统与能效路径

**结论：技术方案成熟，能效目标可实现，但与用户需求存在偏差。**

- **方案选择:** 系统经过多方案寻优，最终推荐了 **“传统房间级CRAC(上送风)+热通道封闭”** 方案，而非用户指定的“浸没式液冷”。该方案充分利用了乌兰察布的自然冷源，预估PUE仅为 **1.229**，优于1.3的目标。
- **能效与水资源消耗:**
    - **PUE:** 1.229，达到行业先进水平。
    - **WUE（水资源利用效率）:** 1.65 L/kWh。该值略高于1.6的限值，表明方案对水资源的消耗较高，在干旱地区需关注。**数据缺失/待补充**：未提供乌兰察布地区的水资源可用性数据，需评估WUE的可持续性。
- **余热回收:** 方案预估可回收 **247.5 kW** 的余热，可用于园区供暖，提升了项目的综合能效和环境友好性。
- **成本:** 制冷系统初始投资仅为 **46.75万元**（约47万元），年运营成本（不含电费）约 **0.94万元**，经济性良好。

**关键指标：**
- 推荐冷却方案：传统房间级CRAC(上送风)+热通道封闭
- 预估PUE：1.229
- 预估WUE：1.65 L/kWh
- 制冷系统投资：46.75万元
- 余热回收潜力：247.5 kW

## 5. 仿真结果解读与运行策略

- **绿电仿真:** 基于乌兰察布2025年典型气象年数据，对160小时（约一周）的运行进行了仿真。结果显示，配置的风光储系统可以完全满足IT负载需求，但存在10%的弃电率。这表明系统设计偏保守，储能容量可能过大。
- **运行策略建议:**
    - **优化储能调度:** 通过更精细的负荷预测和发电预测，优化储能充放电策略，降低弃电率，提高绿电利用率。
    - **“并网不上网”模式:** 与电网保持连接，但不向电网售电。在风光出力不足时，从电网购电作为补充，从而可以大幅降低储能容量需求，显著降低成本。这是解决当前预算问题的关键思路之一。
    - **需求侧响应:** 利用数据中心的灵活性，参与电网的需求侧响应，获取额外收益。

## 6. 财务可行性与投资回收

**结论：财务上暂不可行。** 项目投资远超预算，投资回收期过长。

- **总投资估算:**
    - **系统总成本（经济分析模块）:** 1.11亿元
    - **用户预算:** 2000万元
    - **资金缺口:** 9111万元（超出预算455%）
    - **成本构成:** 绿电系统（98.5%）> 供电系统（1.1%）> 制冷系统（0.4%）。绿电系统，尤其是储能，是成本失控的根源。
- **投资回收期分析:**
    - **经济专家估算:** 基于一个相对独立的假设（总成本1800万元，年净收益150万元），动态回收期约 **8年**，ROI约12%。这个估算与系统总成本1.11亿元严重不符，**数据冲突**。
    - **基于实际成本的修正估算:** 若总投资为1.11亿元，即使考虑绿电带来的电费节省（按分时电价计算，年电费节省约65万元），投资回收期将远超30年，不具备商业可行性。
    - **结论:** 在当前方案下，项目财务模型完全不可行。必须大幅降低初始投资，尤其是储能成本。

**关键指标：**
- 系统估算总投资：1.11亿元
- 用户预算：2000万元
- 资金缺口：9111万元
- 经济专家估算回收期：8年（基于不同假设）
- 实际方案估算回收期：>30年

    4.  **申请预算:** 若新方案总投资在预算范围内，则提交审批；若仍超预算，则需项目方决策。

    4.  **制冷系统建设:** 完成冷却系统（按最终确定的方案）的安装。

## 9. 综合结论与建议

**综合结论：暂不可行。**

本项目在技术层面具备高度的可行性，选址乌兰察布、采用高效制冷和绿电消纳策略，完全有能力建设一个PUE低于1.3、绿电比例高达70%的先进A级数据中心。然而，**财务可行性是决定项目成败的唯一硬约束**。当前方案的总投资（1.11亿元）是预算（2000万元）的5.5倍，存在无法逾越的资金鸿沟。

**核心建议：**

1.  **首要任务：重新审视并调整技术方案。** 必须放弃“风光储孤岛运行”的激进绿电方案。建议采用“市电为主、绿电为辅”的并网模式，将风电/光伏容量降低至满足70%绿电比例即可，将储能容量削减至用于削峰填谷和保障UPS后备时间的合理水平（如5MWh以下）。此举可将绿电系统成本降低80%以上。
2.  **明确冷却技术路线。** 尽快确定采用“浸没式液冷”还是系统推荐的“传统CRAC”方案。若采用液冷，PUE可望降至1.1以下，但初始投资会更高。需进行详细的TCO（总拥有成本）对比分析。
3.  **重新进行财务测算。** 基于调整后的技术方案，重新估算总投资。只有当总投资控制在预算范围内（或项目方同意增加预算至合理水平），项目才具备推进的基础。
4.  **分阶段建设，控制风险。** 即使预算充足，也建议分阶段建设，先部署50%的IT负载，验证技术和商业模式后，再行扩展。
