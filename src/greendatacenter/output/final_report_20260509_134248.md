*   **能效目标：** 目标 PUE 为 1.3，这是一个极具挑战性但通过浸没式液冷技术可以实现的目标。

### **4. 制冷系统与能效路径**

*   **技术选择：** 采用“浸没式液冷”技术，这是实现 PUE 1.3 目标的关键。相比传统风冷，液冷能效更高、散热密度更大、噪音更低。
*   **能效路径：**
    1.  **液冷系统优化：** 采用单相或两相浸没液冷，将 IT 设备热量直接传递给冷却液。
    2.  **高效冷却塔/干冷器：** 利用乌兰察布的低温气候，在绝大多数时间（>3000小时/年）采用自然冷却，仅需开启冷却塔或干冷器即可将液冷系统的热量散发到室外。
    3.  **高温冷冻水：** 提高液冷系统二次侧的供回水温度（如 40-45°C），进一步延长自然冷却时长。
    4.  **低GWP制冷剂：** 环境专家强调，必须使用 GWP 值低于 150 的制冷剂（如 R1234ze），以减少对环境的影响。
*   **PUE 达成分析：** 浸没式液冷系统本身可将 PUE 降至 1.1 以下。结合自然冷却，全年平均 PUE 有望稳定在 1.15-1.25 之间，**完全有能力实现 1.3 的目标**。
