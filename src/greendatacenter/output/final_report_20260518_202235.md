## 2. 设计边界、依据与关键假设

本方案的设计与优化基于以下关键假设与边界条件：

1.  **气象数据**：采用乌兰察布地区2025年全年（8760小时）的模拟气象数据（来源：open-meteo），用于光伏、风电出力及冷却系统性能模拟。
2.  **经济模型假设**：
    - 风电单位造价：420万元/MW
    - 光伏单位造价：350万元/MW
    - 储能单位造价：60万元/MWh
    - 绿电交易溢价：0.03元/kWh
    - 绿证价格：0.015元/kWh
3.  **电网交互**：假设项目为“并网型”，允许从电网购电，并可通过市场化手段采购绿电和绿证。直连部分（30%）遵循“以荷定源、自发自用”原则。
4.  **冷却系统**：多目标优化权重设定为：WUE(0.33) > PUE(0.2) = CUE(0.2) > TCO(0.13) > WHR(0.13)，体现了对水资源消耗的高度关注（乌兰察布地区CWSI指数为0.39，属缺水地区）。
5.  **负载模型**：模拟周（168小时）的平均负载为28.85MW，峰值负载29.99MW，负载率较高且平稳，符合大型数据中心特征。

## 4. 综合技术方案

### 4.1 供配电系统 (A级-110kV供电一体化方案)

- **外部电源**：两路独立的110kV高压市电，每路均可承担100%负荷，满足A级机房容错要求。
- **主变配置**：采用 **“主变N+1”** 冗余，确保单台主变压器故障不影响供电。
- **配变配置**：采用 **“配变2N（互为备用）”** 架构，10kV配电侧实现完全冗余。
- **低压配电**：主机房采用380/220V单母线分段接线，确保电力分配的灵活性与可靠性。
- **柴油发电机**：仅用于消防、安防等保安负荷，不承担IT负载，以降低CAPEX和运维复杂度。IT负载的备用电源由2N架构的UPS保障。
- **预期可用性**：99.98%（Tier III标准），年计划外停机时间约1.6小时。

### 4.2 制冷系统 (分离式热管系统+自然冷却)

- **最终选择**：通过多目标优化（PUE, WUE, TCO, CUE, WHR）评分，**“分离式热管系统+自然冷却”** 以总分0.512（分数越低越优）胜出。该方案在能效、节水和成本之间取得了最佳平衡。
- **核心优势**：
    - **PUE表现**：设计PUE为1.171，优于目标值。
    - **WUE表现**：预测WUE为1.53，远优于行业平均水平，契合乌兰察布水资源紧张的现状。
    - **技术原理**：利用热管的高效相变传热特性，在室外温度较低时，完全或大部分依靠自然冷源进行冷却，大幅降低压缩机运行时间。
- **余热回收**：预计可回收23,595 kW余热，推荐用于园区或周边区域供暖，进一步提升能源综合利用率。

### 4.3 绿色电力消纳与采购策略

本方案采用 **“自发自用 + 市场化采购”** 的混合策略，确保92%的绿电目标。

| 策略层级 | 占比 | 实现方式 | 年电量 (MWh) | 年成本 (万元) |
| :--- | :--- | :--- | :--- | :--- |
| **第一层：直连消纳** | 30% | 自建28.28MW风电 + 2.41MW光伏，通过并网直连 | 92,321.64 | 包含在CAPEX中 |
| **第二层：绿电交易** | 49.6% | 与本地风/光电场签署中长期购电协议 (PPA) | 152,638.44 | 457.92 (溢价部分) |
| **第三层：绿证补足** | 12.4% | 购买绿证 (I-REC/GEC) 覆盖剩余绿色权益 | 38,159.61 | 57.24 |
| **合计** | **92%** | **混合策略** | **283,119.69** | **515.15** |

**采购路径建议**：优先进行本地绿电交易，作为消纳主体；剩余缺口通过购买价格较低的绿证进行补充，以控制成本。

## 综合技术方案深化

综合方案应把制冷、供电、绿电和运维监测视为一个系统，而不是三个孤立子方案。

| 系统 | 推荐配置 | 专业说明 |
| --- | --- | --- |
| 制冷系统 | 分离式热管系统+自然冷却 | 重点校核 PUE、WUE、余热回收和高密机柜适配能力。 |
| 供配电系统 | A级-110 kV 供电一体化方案 | 外部电压：110 kV；冗余等级需与机房等级一致。 |
| 绿电直连 | 30% | 直连比例应结合场址资源、并网条件和负荷曲线复核。 |
| 绿电采购补足 | 绿电交易+绿证补足 | 建议同步配置绿电交易、绿证和碳核算台账。 |
| 风光储容量 | 风电 28.28 MW；光伏 2.41 MWp；储能 3.60 MWh | 容量结果应在全年 8760h 负荷曲线上复核弃电、缺口和储能循环次数。 |
| 可运维性 | 建议建立能源管理系统 EMS + DCIM 联动 | 持续跟踪 PUE、绿电占比、碳排、储能 SOC 与关键设备健康状态。 |
