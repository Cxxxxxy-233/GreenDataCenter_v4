# **乌兰察布 500kW A级绿色数据中心规划可行性报告**

**摘要**

本报告基于用户提供的项目参数与系统仿真结果，对在内蒙古乌兰察布市建设一座500kW、A级、目标PUE 1.3、绿电比例60%的数据中心项目进行全面可行性评估。分析涵盖场址环境、能源系统、制冷方案、财务经济及实施风险等维度。

**核心结论：有条件可行。**

项目在技术方案和预算约束上具备可行性，但存在关键风险与性能偏差，需在实施前进行方案调整与风险缓释。主要风险点在于绿电系统优化未达到目标比例，以及冷却方案选择与用户原始需求存在偏差。

### **1. 项目背景与目标约束**

本项目旨在乌兰察布市建设一座设计IT负载为500kW的A级数据中心。项目核心目标与约束如下：
*   **地理位置**：乌兰察布，内蒙古中部，气候冷凉，利于自然冷却，且为全国一体化算力网络国家枢纽节点之一，政策与资源优势明显。
*   **IT负载**：500 kW。
*   **机房等级**：A级（GB 50174-2017标准），要求容错，即任何单一系统故障不影响业务运行。
*   **能效目标**：PUE ≤ 1.3。
*   **绿色电力目标**：绿电消纳比例 ≥ 60%。
*   **预算约束**：总投资不超过 20,000 万元。
*   **冷却技术**：用户指定为“浸没式液冷”。

**数据完整性评估**：项目参数基本完整。但用户指定的冷却技术与系统优化后推荐的方案存在矛盾，这是本报告需要重点分析的风险点。

---

### **2. 场址与环境可行性**

*   **气候优势**：乌兰察布属于中温带大陆性季风气候，年均气温低（约4.3℃），年均风速大，日照充足。这种气候条件非常有利于数据中心采用自然冷却（如空气侧或水侧节能器），可显著降低制冷能耗，是实现低PUE（<1.3）的天然优势。
*   **能源禀赋**：乌兰察布风能、太阳能资源丰富，是国家级可再生能源基地。这为项目实现高比例绿电消纳提供了坚实的资源基础。项目规划的60%绿电比例在此区域具备良好的资源匹配性。
*   **政策与产业环境**：作为“东数西算”枢纽节点，乌兰察布市对数据中心产业提供土地、税收、电力等多方面政策支持，产业生态日趋成熟，人才和供应链配套相对完善。

**结论**：场址选择在乌兰察布，从气候、能源和政策角度看，是高度合理且具备优势的。

### **3. 能源系统与绿电消纳策略**

根据 `green_power_result` 数据，系统对绿电方案进行了优化仿真。

*   **优化结果**：
    *   **装机配置**：风电 1.16 MW，光伏 2.08 MW，储能 20 MWh。
    *   **总投资**：绿电系统总成本约 6538.39 万元（占项目总投资的97%以上），其中储能成本高达 5000 万元。
    *   **绿电供应比例**：**53.54%**，**未达到用户设定的60%目标**。
    *   **优化状态**：`fallback`（回退模式）。优化器在严格约束下未找到可行解，最终返回了带有惩罚的“尽力而为”方案。约束违规值为 0.37，表明离目标有显著差距。
    *   **弃电率**：**35.3%**，非常高，表明装机容量（特别是光伏）可能过大，导致大量电能无法被消纳或储存。
    *   **市电购买**：几乎为0，表明系统在设计上试图完全依靠绿电+储能自给自足。

*   **问题诊断**：
    1.  **目标未达成**：绿电比例 53.54% 与目标 60% 存在约6.5个百分点的差距，这是一个关键的性能偏差。
    2.  **经济性失衡**：为实现高自给率，配置了巨大的储能系统（20 MWh），其成本（5000万）占据了绿电系统总成本的76%，严重推高了项目总资本开支。考虑到项目总预算为2亿，这一比例过高，投资回报风险极大。
    3.  **弃电严重**：35.3%的弃电率意味着大量可再生能源投资被浪费。这通常是因为储能容量不足以完全吸收过剩发电，或发电曲线与负载曲线不匹配。
    4.  **优化策略失当**：`fallback`状态表明，在现有约束下，同时追求“高绿电比例”和“近乎零市电”的目标是不可行的。更经济的策略应是允许一定比例的市电购入，从而大幅降低对储能的依赖。

*   **调整建议**：
    *   **调整优化目标**：将目标从“完全自给”调整为“最大化绿电消纳比例”，允许按需从电网购电，以平抑波动。
    *   **重新评估储能规模**：将储能容量从20 MWh大幅降低至更经济的水平（例如2-5 MWh），主要用于平滑光伏波动和进行峰谷套利。
    *   **优化装机配比**：根据乌兰察布的风光资源特性，适当提高风电比例，降低光伏比例，因为夜间无光时风电可以持续发电，更有利于匹配数据中心24/7的负载需求。

### **4. 制冷系统与能效路径**

*   **用户需求 vs. 系统推荐**：
    *   **用户需求**：指定使用“浸没式液冷”。
    *   **系统推荐**：经过多方案打分（权重偏向经济型），最终选择了 **“传统房间级CRAC(上送风)+热通道封闭”** 方案，得分 0.522。而“单相浸没式液冷+干冷器”方案得分 0.950，排名第18位，远非最优。

*   **方案对比分析**：
    *   **推荐方案（传统风冷）**：
        *   **PUE**：1.229（优于目标1.3）
        *   **WUE**：1.65（略高于1.6的目标，需关注）
        *   **TCO（总拥有成本）得分**：0.65（较低，表示成本低）
        *   **优势**：初期投资极低（46.75万元），技术成熟，运维简单。
        *   **劣势**：能效提升空间有限，PUE 1.229在乌兰察布的气候优势下并非最优解。
    *   **用户指定方案（浸没式液冷）**：
        *   **PUE**：1.08（单相）~ 1.05（两相），非常优秀。
        *   **WUE**：0.1（单相）~ 0.05（两相），节水效果极佳。
        *   **TCO得分**：1.9（单相）~ 2.2（两相），非常高，意味着成本高昂。
        *   **优势**：极致能效、高密度部署、低噪音、余热回收价值高。
        *   **劣势**：初期投资巨大（是风冷的数倍至数十倍），对运维团队技术要求高，存在技术成熟度风险。

*   **矛盾与风险**：
    系统基于“经济型”权重（TCO权重0.4），选择了成本最低的方案，但这与用户指定的“浸没式液冷”技术路线完全冲突。如果强行采用风冷方案，将无法满足用户对高密度、极致能效和未来技术演进的需求。

*   **推荐路径**：
    1.  **明确用户真实意图**：用户指定“浸没式液冷”是出于何种考虑？是追求极致PUE、高密度部署、还是为了余热利用？需要澄清。
    2.  **调整优化权重**：如果用户坚持液冷，应将优化权重从“经济型”调整为“能效型”或“综合最优型”，重新进行方案打分。
    3.  **折中方案**：可以考虑 **“冷板式液冷+水侧自然冷却(干冷器)”** 方案。该方案PUE为1.12，WUE为0.8，TCO得分1.1，在能效、节水和成本之间取得了较好的平衡，是当前数据中心行业的主流选择，技术成熟度也较高。

### **5. 仿真结果解读与运行策略**

*   **绿电仿真**：160小时的仿真显示，系统在无市电输入的情况下，通过风光储协同，实现了53.54%的绿电供应。但高弃电率表明运行策略需要优化。
*   **运行策略建议**：
    *   **日前调度**：基于次日的气象预测（风速、光照），提前规划储能充放电策略。在预测到光伏大发时段，提前为储能充电；在预测到风光出力不足时，提前放电或从电网购电。
    *   **实时控制**：采用微电网能量管理系统，实时监控发电、负载和储能状态，动态调整各单元出力，确保供电稳定。
    *   **需求响应**：与电网公司合作，利用低谷电价时段为储能充电，在高峰电价时段放电，实现峰谷套利，降低运营成本。
    *   **余热利用**：无论最终采用何种冷却方案，都应积极规划余热回收系统。247.5 kW的余热可用于园区供暖、温室大棚或预热新风，创造额外收益。

*   **总投资**：`economic_analysis_result` 显示总资本支出为 **6710.14 万元**，远低于 20,000 万元的预算上限，预算结余 13,289.86 万元。

    *   供电系统：125.00万元（1.9%）
    *   制冷系统：46.75万元（0.7%）
*   **财务指标**：
    *   **ROI（投资回报率）**：12%（低于行业平均15%）。
    *   **投资回收期**：8年（长于行业标准7年）。
    *   **单机架成本**：108.23万元。
*   **财务风险分析**：
    1.  **投资结构严重畸形**：97%的投资集中在绿电系统，特别是储能，而核心的IT设备、土建、供电、制冷等投资占比极低，这不符合数据中心建设的常规资金分配。这种结构意味着项目的大部分资金被用于“发电”，而非“用算力”，经济账算不过来。
    2.  **ROI偏低**：12%的ROI和8年的回收期，在当前高利率和快速技术迭代的环境下，投资吸引力不足。任何市场波动（如机架出租率下降、电价上涨）都可能使回收期延长至10年以上。
    3.  **预算结余巨大**：2亿的预算只用了6700万，结余1.3亿。这并非好事，说明投资计划过于保守，或者未将IT设备、土建、网络等核心成本纳入。这份经济分析报告很可能是不完整的。

*   **调整建议**：
    *   **重新核算总成本**：必须将服务器、交换机、光模块、综合布线、土建装修、消防、安防等核心成本纳入总预算。一个500kW的数据中心，仅服务器投资就可能达到数千万甚至上亿元。
    *   **优化投资结构**：大幅削减储能投资，将资金用于提升IT设备性能、建设高可靠性配电系统和更高效的制冷系统。
    *   **重新评估商业模式**：明确项目的盈利模式（自用、托管、云计算等），并基于此进行更精准的财务测算。

### **9. 综合结论与建议**

**综合结论：有条件可行。**

项目在选址、预算总额、供电架构等基础条件上具备可行性。但是，当前方案在 **绿电系统经济性** 和 **冷却技术路线** 两个核心维度上存在严重偏差，导致项目无法满足用户原始需求，且财务模型存在重大缺陷。

**核心建议：**

1.  **暂停当前方案，立即启动方案修正**。不应基于现有结果继续推进。
2.  **明确核心诉求**：与项目方确认，是追求“极致绿电”（不惜成本）还是“经济可行的高效绿电”？是“技术前瞻的液冷”还是“成熟经济的风冷”？
3.  **采纳“混合策略”**：
    *   **能源**：放弃“零市电”目标，采用“自建风光储 + 市电购电”的混合模式。将储能规模降低至经济水平，将节省的资金用于提升IT设备或优化制冷。
    *   **制冷**：推荐采用 **“冷板式液冷 + 干冷器”** 或 **“房间级间接空气侧自然冷却”** 方案，在能效、成本和可靠性之间取得最佳平衡。
4.  **重新进行全口径财务测算**：将IT设备、土建、人工等所有成本纳入，编制一份真实的、完整的财务模型，以此作为投资决策的唯一依据。
