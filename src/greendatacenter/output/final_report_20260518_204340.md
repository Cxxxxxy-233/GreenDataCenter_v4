## 1. 项目概况与基础输入

### 1.1 项目背景

本项目拟在内蒙古自治区乌兰察布市建设一座绿色、高效、高可靠性的A级数据中心，以满足日益增长的算力需求，并响应国家“双碳”战略目标。乌兰察布地区具备丰富的风、光资源，为绿电消纳提供了天然优势。

### 1.2 用户核心输入

| 参数 | 数值 | 备注 |
|------|------|------|
| 选址地点 | 乌兰察布 | 气候冷凉，利于自然冷却；绿电资源丰富 |
| 规划IT负载 | 30,000 kW | 总IT设备电力容量 |
| 规划用地面积 | 15,000 m² | 待确认实际建筑密度及园区布局 |
| 绿电消纳目标 | 92% | 包含直连绿电及市场化采购 |
| 预算上限 | 32,000 万元 | 含供电、制冷、绿电系统CAPEX |
| 制冷技术偏好 | 浸没式液冷 | 经多方案比选后优化为分离式热管系统+自然冷却 |
| 机房等级 | A级 | 符合GB 50174 A级标准 |
| PUE目标 | ≤1.22 | 设计目标值 |
| 算力密度 | 20 kW/机架 | 高密度部署 |
| 碳排因子 | 0.57 kgCO₂/kWh | 电网排放因子（待确认是否为乌兰察布本地因子） |

### 1.3 关键假设

1.  **电价模型**：采用内蒙古峰谷分时电价，加权平均约0.348元/kWh。绿电溢价0.03元/kWh，绿证价格0.015元/kWh。
2.  **气象数据**：基于Open-Meteo 2025年历史气象数据，用于风光出力模拟。
3.  **设备成本**：风电4,200元/kW，光伏3,500元/kW，储能600元/kWh（均为当前市场参考价）。
4.  **融资假设**：未纳入融资成本，ROI及回收期基于全自有资金测算。

| 边界项 | 设定值 | 依据/说明 |
|--------|--------|-----------|

| 储能容量下限 | 3.6 MWh | 满足削峰填谷及波动缓冲基本需求 |

- **供电可靠性**：按Tier III等级设计，采用“主变N+1，配变2N”冗余架构，确保单一组件故障不影响业务运行。

## 4. 综合技术方案

### 4.1 供电与可靠性方案

**方案名称：** A级-110 kV供电一体化方案

| 项目 | 配置 | 说明 |
|------|------|------|
| 外部电源 | 两路独立110 kV电源 | 每路可承载100%负荷 |
| 主变压器 | N+1冗余 | 单台故障不影响供电 |
| 配电变压器 | 2N冗余，单台2.5 MVA | 互为备用，支持在线维护 |
| 次级电压 | 10 kV | 经济性最优，适配设备选型 |
| 末端配电 | 380/220V单母线分段 | 关键负载双路供电 |
| 柴油发电机 | 仅用于保安负荷 | 非主用电源，降低运维成本 |
| 预期可用性 | 99.98% | 对应年停机≤1.75小时 |

### 4.2 制冷方案

**最终选型：** 分离式热管系统 + 自然冷却

**选型逻辑：** 经多方案多目标优化（PUE权重0.2，WUE权重0.33，TCO权重0.13，CUE权重0.2，WHR权重0.13），该方案综合得分0.512，为最优解。

| 指标 | 数值 | 说明 |
|------|------|------|
| 预测PUE | 1.171 | 优于目标值1.22 |
| 预测WUE | 1.53 L/kWh | 低于缺水地区警戒线 |
| 制冷功耗 | 3,039.47 kW | 占IT负载10.13% |
| 余热回收潜力 | 23,595 kW | 可用于园区供暖或预热新风 |
| 初始投资 | 7,986 万元 | 含设备、安装、调试 |

**技术优势：**
- 利用乌兰察布冷凉气候，最大化自然冷却时长。
- 分离式热管无运动部件，维护成本低，可靠性高。
- 水耗极低（WUE=0.05），契合缺水地区要求。

### 4.3 绿电消纳与储能方案

**消纳路径：**

```
总绿电目标 92%
├── 直连绿电 30% (自建风光储系统)
│   ├── 风电 28.28 MW
│   ├── 光伏 2.41 MW
│   └── 储能 3.60 MWh
└── 市场化采购 62%
    ├── 绿电交易 49.6% (152,638.44 MWh/年)
    └── 绿证补足 12.4% (38,159.61 MWh/年)
```

**储能策略：** 储能系统主要用于平滑风光出力波动、削峰填谷，不承担长时间备电功能。模拟周内储能充放电量分别为7.40 MWh和7.80 MWh，充放效率约95%。

## 综合技术方案深化

综合方案应把制冷、供电、绿电和运维监测视为一个系统，而不是三个孤立子方案。

| 系统 | 推荐配置 | 专业说明 |
| --- | --- | --- |
| 制冷系统 | 分离式热管系统+自然冷却 | 重点校核 PUE、WUE、余热回收和高密机柜适配能力。 |
| 供配电系统 | A级-110 kV 供电一体化方案 | 外部电压：110 kV；冗余等级需与机房等级一致。 |
| 绿电直连 | 30% | 直连比例应结合场址资源、并网条件和负荷曲线复核。 |
| 绿电采购补足 | 绿电交易+绿证补足 | 建议同步配置绿电交易、绿证和碳核算台账。 |
| 风光储容量 | 风电 28.28 MW；光伏 2.41 MWp；储能 3.60 MWh | 容量结果应在全年 8760h 负荷曲线上复核弃电、缺口和储能循环次数。 |
| 可运维性 | 建议建立能源管理系统 EMS + DCIM 联动 | 持续跟踪 PUE、绿电占比、碳排、储能 SOC 与关键设备健康状态。 |
