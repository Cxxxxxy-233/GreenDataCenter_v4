# 乌兰察布 30MW 绿色数据中心项目可行性综合评估报告

## 摘要

本报告基于用户提供的项目参数、专家意见及仿真结果，对在乌兰察布建设一座30MW、A级、采用浸没式液冷技术、目标PUE为1.22、绿电消纳比例为30%的数据中心项目进行全面的可行性评估。评估结论为：**有条件可行**。项目在供电架构、绿电消纳方案、制冷技术选型和财务预算方面均表现出较高的可行性，但存在关键数据缺失（如具体建设日期），且在经济回报、环保合规及运营可靠性方面存在潜在风险，需在后续阶段予以明确和规避。

### 1. 项目背景与目标约束

本项目计划于2025年在内蒙古乌兰察布建设一座总规划IT负载为30MW的A级数据中心。用户明确提出了以下核心目标与约束：
- **绿电消纳比例**：30%
- **目标PUE**：1.22
- **制冷技术**：浸没式液冷
- **预算上限**：32,000万元（3.2亿人民币）
- **场地面积**：15,000平方米

这些目标构成了项目规划的核心约束条件，所有后续的电源、制冷、绿电方案均需在此框架内寻求最优解。

### 2. 场地与环境可行性

项目选址于内蒙古乌兰察布，该地区具有显著的区位优势：
- **气候优势**：乌兰察布属于中温带大陆性季风气候，年平均气温低，冬季漫长寒冷，为自然冷却提供了得天独厚的条件，有利于降低制冷能耗，是实现低PUE目标的关键。
- **能源优势**：乌兰察布是蒙西电网的核心区域，风电和光伏资源丰富，是“西电东送”的重要枢纽。这为项目实现30%的绿电消纳目标提供了充足且成本相对较低的可再生能源供应。绿电优化结果也证实了这一点，其资源丰度评级为“rich”。
- **地质与政策**：该地区地质结构稳定，且地方政府对大数据、云计算产业有明确的政策支持和优惠措施，有利于项目的快速落地。

**结论**：场地与环境条件高度契合项目目标，是项目可行性的重要基石。

### 3. 能源系统与绿电消纳策略

项目采用了“并网型绿电直连”模式，通过优化算法配置了自建可再生能源电站。
- **供电方案**：采用“A级-110 kV 供电一体化方案”，双路110kV外部电源接入，主变N+1、配变2N冗余，完全满足A级机房的容错要求，供电可靠性高。
- **绿电消纳方案**：优化结果显示，为满足30%的绿电消纳目标，需配置约28.28MW的风电和2.41MW的光伏，以及极小容量的储能（2.3MWh，实际可忽略）。方案实现了0%的弃电率，绿电供应比例精确达到30.0%。这意味着项目将主要通过自建风电场来满足绿电需求，光伏作为补充。
- **电网交互**：在168小时的仿真周期内，项目仍需从电网购电约3393 MWh，表明自建绿电无法完全覆盖负荷，项目为“并网型”而非“离网型”。这符合“以荷定源、自发自用、减少向公网反送”的政策导向。

**结论**：能源系统方案设计合理，绿电消纳策略可行且高效。自建风电场的方案在乌兰察布具有经济性，但需关注大规模风电并网对电网稳定性的影响，以及相关审批流程。

### 4. 制冷系统与能效路径

用户指定采用“浸没式液冷”，但经过冷却系统多方案寻优后，最终推荐了 **“分离式热管系统+自然冷却”** 方案。
- **技术选择分析**：尽管用户偏好浸没式液冷，但专家系统基于“环保型”偏好（高权重WUE）和乌兰察布的气候条件，对20余种方案进行了打分。分离式热管系统+自然冷却方案以最低的综合得分（0.512，得分越低越好）胜出。其预测PUE为1.171，WUE仅为0.05，TCO代价适中，完美平衡了能效、节水和成本。
- **性能指标**：预测PUE（1.171）优于用户目标（1.22），表明该方案能效极高。预测WUE（1.53）低于乌兰察布地区水资源压力指数（0.39）下的WUE限值（1.6），节水效果显著。
- **余热回收**：方案预计可回收23.6MW的余热，可用于园区供暖或预热新风，具有显著的附加经济价值和环保效益。

**结论**：虽然用户偏好浸没式液冷，但专家系统推荐的“分离式热管系统+自然冷却”方案在技术上更优、更经济、更环保。**此处存在用户需求与技术方案推荐的偏差**，需与用户沟通确认是否接受此更优方案。若坚持浸没式液冷，PUE可更低（如1.05-1.08），但TCO代价会显著增加。

### 5. 仿真结果解读与运行策略

基于168小时的仿真，项目运行策略清晰：
- **运行模式**：项目以“自发自用，余电不上网”为主要模式。自建的风光电站优先为数据中心供电，不足部分由电网补充。由于配置的储能容量极小，其作用更偏向于平抑瞬时功率波动，而非进行削峰填谷或套利。
- **绿电供应**：风电是绿电的主力，在风资源丰富的时段，数据中心可完全由绿电供电。光伏在日间提供补充。
- **电网依赖**：在无风或夜间无光时段，数据中心将完全依赖电网供电。优化结果中电网购电量占比约70%，与30%的绿电目标一致。

**结论**：仿真结果验证了方案的可行性，运行策略简单有效。未来可考虑适当增加储能容量，以提升绿电消纳的灵活性，并降低对电网的依赖。

### 6. 财务可行性与投资回收

- **总投资**：项目总CAPEX估算为29,857.12万元，低于32,000万元的预算上限，留有约2,142.88万元的预算余量。预算执行情况良好。
- **成本构成**：绿电系统（风电+光伏）CAPEX最高，为12,721.12万元，占总投资的42.6%；其次是供配电系统（9,150万元，占30.6%）和冷却系统（7,986万元，占26.7%）。
- **经济指标**：经济专家评估的ROI为12%，低于行业基准15%；投资回收期为8年，处于行业典型周期（7-10年）的上限。这表明项目盈利能力和资本效率有待提升。
- **运营成本**：年运营电费约2,921.02万元，是运营成本的主要部分。由于全部绿电由自建电站直供，无额外的绿电交易或绿证采购成本。

**结论**：项目在预算内可行，但经济回报率偏低。主要原因是自建风电场的初始投资巨大，拉高了CAPEX。虽然长期来看可规避电价上涨风险，但短期财务压力较大。建议通过优化融资结构、申请政府补贴或分阶段建设来改善现金流。
