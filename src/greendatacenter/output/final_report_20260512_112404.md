# 乌兰察布 500kW 绿色数据中心项目可行性总报告

## 摘要

本报告针对位于内蒙古乌兰察布市，规划负载500kW，目标PUE 1.3，绿电比例70%的A级数据中心项目进行综合可行性评估。项目采用了浸没式液冷技术，并计划通过风光储一体化系统实现高比例绿电消纳。

**核心结论：项目在技术层面具备“有条件可行”的基础，但在经济层面“暂不可行”。**

主要矛盾在于：为实现70%的绿电比例，系统优化出的风光储配置方案（1MW风电 + 1MW光伏 + 39.6MWh储能）导致总投资高达1.1亿元人民币，远超用户2000万元的预算约束。尽管专家意见显示项目在技术可靠性、能效和环境友好性方面表现优异，但经济性成为当前无法逾越的障碍。**项目需要从预算、绿电目标或技术方案上进行根本性调整。**

## 1. 项目背景与目标约束

本项目旨在乌兰察布市建设一座高标准、高能效、高绿电比例的绿色数据中心。核心参数如下：

*   **地点**：乌兰察布 (内蒙古)，具备丰富的风、光资源和较低的环境温度，为自然冷却和绿电消纳提供了天然优势。
*   **规模**：IT负载500kW，规划面积500㎡，属于中小型数据中心。
*   **能效目标**：PUE ≤ 1.3，属于行业领先水平。
*   **绿色目标**：绿电比例 ≥ 70%，体现了强烈的可持续发展意愿。
*   **可靠性等级**：A级（GB 50174-2017），要求容错，即任何单一组件故障不影响业务运行。
*   **预算约束**：2000万元人民币，这是一个非常严格的约束。
*   **制冷技术**：用户要求“浸没式液冷”，但系统在寻优后选择了“传统房间级CRAC(上送风)+热通道封闭”。这是一个关键矛盾点。

**分析**：项目的技术目标（高能效、高绿电、高可靠性）与财务目标（低预算）之间存在显著冲突。乌兰察布的地理位置为技术实现提供了便利，但无法解决经济层面的根本矛盾。

## 2. 场址与环境可行性

乌兰察布地区具有建设绿色数据中心的显著优势：

*   **气候优势**：年均气温低，全年大部分时间可利用自然冷却，为降低PUE提供了天然条件。系统最终选择的“传统房间级CRAC(上送风)+热通道封闭”方案，其PUE可低至1.229，正是利用了当地气候特点。
*   **能源优势**：作为国家重要的新能源基地，乌兰察布的风电和光伏资源丰富，电网基础设施相对完善，便于接入绿电。系统优化出的1MW风电和1MW光伏配置，在资源上是可行的。
*   **土地与政策**：乌兰察布土地资源相对充裕，且地方政府对大数据、新能源产业有明确的政策支持，为项目落地提供了良好环境。

**结论**：场址与环境条件非常优越，**不存在物理或政策层面的障碍**。然而，优越的自然条件并未能有效降低为实现高绿电目标而必须配置的储能成本。

## 3. 能源系统与绿电消纳策略

*   **供电方案**：采用了A级标准的“35 kV 供电一体化方案”，双路独立市电引入，主变N+1，配变2N冗余，柴油发电机仅用于保安负荷。该方案完全符合A级机房容错标准，可靠性极高。但成本也相应较高（125万元）。
*   **绿电系统**：为实现70%的绿电比例，优化算法给出了一个激进的配置：**风电1MW，光伏1MW，储能39.6MWh**。
    *   **分析**：该配置下，绿电供应比例（`green_supply_ratio`）达到了100%，远超70%的目标。这是因为系统在160小时的模拟周期内，通过大量储能（近40MWh）来平滑风光出力的间歇性，实现了完全脱离市电（`grid_purchase_mwh`近乎为0）的独立运行。但这导致了极高的储能成本（9889.4万元），占总投资的89%以上。
*   **矛盾点**：**绿电消纳策略过度依赖储能**。虽然实现了100%的绿电自给，但经济代价巨大。一个更经济的策略可能是接受一定比例的市电购电，降低储能容量，从而在满足70%绿电比例的同时控制成本。用户预算仅2000万，而仅储能系统就接近1亿，说明当前优化目标（最小化市电购电）与用户预算约束严重不匹配。

## 4. 制冷系统与能效路径

这是本报告中一个**重大的数据矛盾点**。

*   **用户要求**：`"cooling_technology": "浸没式液冷"`
*   **系统决策**：`"最终决策": "传统房间级CRAC(上送风)+热通道封闭"`

**分析**：
1.  **技术可行性**：系统通过多方案打分，认为“传统房间级CRAC(上送风)+热通道封闭”方案在PUE（1.229）、WUE（1.65）和TCO（0.65）的综合得分最高（0.522，分数越低越好）。该方案在乌兰察布的气候下确实能实现低于1.3的PUE目标。
2.  **决策逻辑**：系统评估认为浸没式液冷方案虽然PUE更低（如单相浸没式液冷PUE可达1.08），但TCO代价极高（得分1.9），在经济性上不占优势。这与用户“浸没式液冷”的原始要求相悖。
3.  **数据缺失/待补充**：`cooling_result`中的`cooling_technology`字段与`user_requirement`中的不一致。**用户需要明确是坚持采用浸没式液冷，还是接受系统推荐的更经济的方案？** 如果坚持液冷，需要重新评估其成本，并可能进一步推高总投资。

**结论**：从能效和成本综合来看，系统推荐的方案是合理的。如果接受此方案，PUE目标1.3完全可以实现。若坚持浸没式液冷，则需要更新`state_json`中的`cooling_technology`字段，并重新进行经济性评估。

## 5. 仿真结果解读与运行策略

*   **仿真时长**：160小时（约6.7天），**数据缺失/待补充**：这是否能代表全年运行工况？建议进行全年8760小时的仿真，以更准确地评估储能需求和弃风弃光率。
*   **弃风弃光率**：`curtailment_ratio: 0.1` (10%)。在100%绿电自给的策略下，仍有10%的清洁能源被浪费，说明储能容量可能存在过度配置或运行策略有待优化。
*   **运行策略**：当前策略是“孤岛运行”，即完全依赖风光储。一个更优的策略是“并网运行”，即：
    *   平时以风光为主，市电作为补充和备用。
    *   储能主要用于削峰填谷和应对风光出力波动，而非追求100%自给。
    *   当风光出力过剩时，可以制氢或向电网售电。

**建议**：重新设定优化目标，从“最小化市电购电”改为“在满足70%绿电比例和预算约束下，最小化总成本”。这将大幅降低储能需求，使项目经济性得到根本改善。

## 6. 财务可行性与投资回收

这是项目当前面临的最大挑战。

*   **系统计算**：
    *   总投资（`total_capex_lakh`）：11,064.4万元（约1.1亿元）
    *   用户预算（`budget_constraint_lakh`）：2,000万元
    *   **超预算**：9,064.4万元（约9064万元），超预算450%以上。
*   **专家意见（经济分析专家-张）**：
    *   专家估算总成本为1800万元，在预算内。
    *   **分析**：专家的估算（1800万）与系统计算（1.1亿）存在巨大差异。原因在于专家的估算基于“典型中型数据中心”，并未考虑为实现70%绿电比例而配置的庞大风光储系统。专家的模型假设了更低的绿电比例或更常规的供电方案。
*   **投资回收期**：专家估算为8年，ROI为12%。但这是在1800万投资基础上的估算。如果投资变为1.1亿，在收入不变的情况下，回收期将延长至约50年，ROI将降至2%以下，完全不具备商业可行性。

**结论**：**财务可行性为“暂不可行”**。核心原因是实现高绿电比例所需的储能成本过高。项目必须进行以下一项或多项调整：
1.  **大幅降低绿电比例**：例如降至30%-50%，可显著减少储能配置。
2.  **增加项目预算**：预算需提高至1亿元以上。
3.  **优化绿电方案**：放弃孤岛运行，采用并网模式，接受一定比例的市电，降低储能容量。
