# 乌兰察布绿色数据中心项目可行性总报告

**报告摘要**

本报告针对位于内蒙古乌兰察布、规划IT负载30MW、目标PUE 1.22、绿电比例92%的A级数据中心项目进行全面的可行性评估。基于现有数据，项目在技术层面**有条件可行**。核心优势在于：选址乌兰察布具备天然的冷源与绿电优势；供电架构符合A级容错标准；冷却方案（分离式热管+自然冷却）能效优异；绿电消纳策略清晰（直连+绿电交易+绿证）。主要挑战在于：经济性方面，高绿电比例与高可靠性架构（配变2N）导致CAPEX（30,073.12万元）逼近预算上限（32,000万元），ROI（12%）和回收期（8年）对运营成本敏感；环境方面，尽管绿电比例高，但配变冗余造成的额外损耗对PUE有负面影响。专家共识认为，通过将配变冗余从2N降为N+1、将绿电比例从92%协调至80%等折中方案，可在保持高可用性（99.98%）的前提下，显著提升经济性并降低环境影响。**数据完整性良好**，但关于具体的储能配置容量（专家建议10MWh vs. 优化结果3.6MWh）存在不一致，需进一步明确。

**结论：有条件可行**

### 1. 项目背景与目标约束

本项目旨在乌兰察布建设一座30MW的A级绿色数据中心。核心目标包括：
- **能效目标**：PUE ≤ 1.22。
- **绿色目标**：绿电使用比例 ≥ 92%。
- **可靠性目标**：满足A级机房容错标准（Tier III）。
- **经济约束**：总投资预算不超过32,000万元。

项目已明确采用“浸没式液冷”作为冷却技术方向，并设定了算力密度（20kW/机柜）、碳排放因子（0.57）等关键参数。这些目标构成了项目规划的刚性约束条件。

### 2. 场址与环境可行性

**结论：高度可行**

- **气候优势**：乌兰察布地处内蒙古，年平均气温低，具备长达数月的自然冷却期。这为“分离式热管系统+自然冷却”方案提供了绝佳的应用条件，是项目实现超低PUE（<1.2）的天然优势。
- **绿电资源**：乌兰察布风光资源丰富，是国家重要的可再生能源基地。项目周边具备接入大型风电场和光伏电站的条件，为达成92%的高绿电比例提供了资源基础。
- **水资源**：冷却系统优化显示，项目最终选择了WUE（水利用效率）仅为0.05 L/kWh的“分离式热管系统+自然冷却”方案，对当地水资源压力极小，环境友好性突出。

### 3. 能源系统与绿电消纳策略

**结论：策略清晰，但存在数据矛盾**

- **供电架构**：采用“110 kV两路独立电源+主变N+1+配变2N”的A级供电方案，完全满足Tier III容错标准，可靠性高达99.98%。这是项目高可用性的基石。
- **绿电消纳**：方案采用“并网型绿电直连+绿电交易+绿证补足”的混合策略。其中，30%的绿电通过直连方式消纳，62%通过市场化绿电交易和绿证采购补齐，总计达到92%的绿电目标。该策略符合国家政策导向，并充分考虑了乌兰察布本地的绿电资源禀赋。
- **数据矛盾**：**需关注**。`green_power_result`中的优化结果与`power_reliability_opinion`中的专家建议存在冲突。
    - 优化模型给出的储能配置仅为**3.6 MWh**，主要用于平抑小时级波动。
    - 电力可靠性专家李工强烈建议配置**10 MWh**的锂电池储能，以应对92%高绿电比例下的电网波动风险，确保供电连续性。
    - 该矛盾直接影响项目的**供电可靠性**和**投资成本**，需在后续设计中明确储能容量的最终取值。

### 4. 制冷系统与能效路径

**结论：方案领先，能效优异**

- **最终选择**：经过多方案综合评分（PUE、WUE、TCO、CUE、WHR），系统最终选择了“分离式热管系统+自然冷却”方案。该方案在乌兰察布的气候条件下，能够最大化利用自然冷源，实现极低的制冷能耗。
- **能效指标**：预计PUE可达**1.171**，优于项目设定的1.22目标。WUE仅为**0.05 L/kWh**，近乎无水冷却，环保效益显著。冷却系统COP高达4.18，能效水平行业领先。
- **余热回收**：预计可回收23.6 MW的余热，可用于园区供暖或周边社区，进一步提升能源综合利用效率，符合绿色数据中心发展方向。

### 5. 仿真结果解读与运行策略

- **仿真验证**：基于乌兰察布2025年气象数据的168小时仿真显示，在配置28.3MW风电、2.4MW光伏和3.6MWh储能的情况下，可达成30%的绿电直供比例。总绿电比例达到92%是通过额外采购绿电和绿证实现的。
- **运行策略**：项目运行策略为“自发自用，余电不上网”。直连的绿电优先满足数据中心负荷，不足部分从电网购电，并通过绿电交易和绿证确保整体绿电比例的达标。储能主要用于平滑可再生能源的短时波动，提高供电质量。

### 6. 财务可行性与投资回收

**结论：处于预算边缘，经济性对方案调整敏感**

- **CAPEX分析**：项目总CAPEX预计为**30,073.12万元**，低于32,000万元的预算上限，留有约1,927万元的缓冲空间。其中，绿电系统（12,937万元）和供电系统（9,150万元）是投资大头。
- **OPEX分析**：年运营成本约515万元（绿电采购），年电费约2,921万元。高绿电比例带来的溢价是运营成本的主要驱动因素。
- **投资回报**：当前方案ROI约为12%，回收期约8年。经济专家张工指出，配变2N冗余和92%绿电比例是成本偏高的主因，并提出了折中方案：**配变降为N+1，绿电比例降至80%**，预计可将总成本降至约1,755万元（此处应为总CAPEX的下降，但原文数据单位有误，结合上下文应为总成本下降），ROI提升至12.8%，回收期缩短至7.8年。

### 9. 综合结论与建议

**综合结论：本项目在乌兰察布建设30MW绿色数据中心，从技术、环境、政策角度看是高度可行的。** 项目充分利用当地气候和资源优势，选择了先进的制冷和供电方案，绿电消纳路径清晰。当前面临的主要挑战在于如何在高可靠性、高绿电比例与经济性之间取得最佳平衡。

**核心建议：** 强烈建议项目组采纳由经济、电力、环境三位专家共同论证的**折中方案**：
1.  **配电冗余优化**：将配变冗余从2N降为N+1。此举可节省约10%的电气成本，降低PUE约0.05-0.08，同时通过主变N+1和N+2柴油发电机补偿，仍可确保99.98%的可用性目标。
2.  **绿电比例协调**：将绿电比例目标从92%协调至80%。此举可显著降低每年的绿电溢价采购成本，同时仍能达到“优秀级”的绿色标准，碳排量在可接受范围内。
3.  **储能容量确认**：将储能系统容量从3.6MWh提升至10MWh，以保障高比例绿电接入下的供电可靠性，这是确保方案可行性的关键前提。

通过上述调整，项目可在**不牺牲核心可靠性**的前提下，显著提升经济性（ROI提升至12.8%，回收期缩短至7.8年），并优化能效表现，实现经济效益与环境效益的共赢。
