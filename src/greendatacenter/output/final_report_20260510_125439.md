# 乌兰察布市 500kW 绿色数据中心项目可行性研究报告

## 摘要

本报告针对拟在内蒙古乌兰察布市建设的500kW（IT负载）绿色数据中心项目进行全面的可行性分析。项目采用浸没式液冷技术，目标PUE为1.3，绿电消纳比例要求70%，总投资预算2000万元。经过对场址环境、能源系统、制冷方案、财务指标及潜在风险的综合评估，**本项目被评定为“有条件可行”**。

核心优势在于乌兰察布市优越的气候条件（低温时间长）与丰富的可再生能源资源，为采用浸没式液冷和实现高绿电比例提供了天然基础。然而，项目当前面临关键数据缺失、经济性分析存在分歧以及专家意见基于不同假设（如IT负载800kW vs 500kW）等重大挑战。必须在补充关键数据、统一技术基线、并验证经济模型后，方可进入下一阶段。**主要风险点在于：** 1) 绿电消纳的具体技术方案与成本尚未明确；2) 经济分析专家与系统计算结果存在显著差异，投资回收期偏长；3) 电力可靠性专家基于800kW负载的设计建议与项目实际500kW负载不符，可能导致过度投资。

## 1. 项目背景与目标约束

本项目旨在乌兰察布市建设一座高效、绿色的中小型数据中心，以满足特定业务负载需求。项目核心目标与约束条件如下：

*   **地理位置：** 内蒙古乌兰察布市。该地区以气候凉爽、电力资源丰富、可再生能源（尤其是风电）比例高而闻名，是建设绿色数据中心的理想选址。
*   **规划负载：** 500 kW（IT设备负载）。
*   **绿色电力比例：** 70%。这是一个具有挑战性但符合行业发展趋势的目标。
*   **能效目标：** PUE ≤ 1.3。结合浸没式液冷技术，此目标在技术上具有可实现性。
*   **制冷技术：** 浸没式液冷。这是一种高效散热技术，特别适合高密度计算场景，并能显著降低制冷能耗。
*   **机房等级：** A级（等同于Tier III级），要求高可用性。
*   **投资预算：** 2000万元。这是项目的硬性财务约束。
*   **建设面积：** 500平方米。

## 2. 场址与环境可行性

*   **气候优势：** 乌兰察布市年均气温较低（约4.3℃），全年大部分时间可以利用自然冷却。这为浸没式液冷系统提供了极佳的散热条件，可大幅减少机械制冷（如冷水机组）的运行时间，是实现PUE 1.3目标的关键保障。环境专家Wang的评估（PUE得分0.95）也印证了这一点。
*   **可再生能源潜力：** 乌兰察布是“风电之都”，风能资源极为丰富，光伏资源也较好。这为实现70%的绿电比例提供了充足的资源保障。项目可考虑自建部分分布式风电/光伏，或通过绿电交易/PPA（购电协议）采购绿电。
*   **碳排放分析：** 基于500kW IT负载、PUE 1.3、年运行8760小时计算，总功耗为650kW。若完全使用火电（碳排放因子0.5 kg CO₂/kWh），年碳排放约2,847吨。若实现70%绿电，则年碳排放可降至约854吨。环境专家Wang的计算基于800kW负载，导致其碳排放估算值（1,367吨）偏高，需修正。
*   **结论：** 场址环境条件**高度可行**。气候和能源禀赋是项目的最大优势。

## 3. 能源系统与绿电消纳策略

*   **现状分析：** `state_json`中`power_supply_plan`和`green_power_result`均为空，表明**能源系统方案和绿电消纳策略尚未制定**。这是当前最大的数据缺失项。
*   **关键问题：**
    1.  **绿电实现路径：** 是自建（风电/光伏+储能），还是外购（PPA/绿证）？自建方案初期投资高，但长期运营成本低；外购方案初期投资低，但受市场电价和供应稳定性影响。两种路径的财务模型差异巨大。
    2.  **储能配置：** 电力可靠性专家李明确指出，绿色能源必须通过储能缓冲。储能系统的容量（决定平滑间歇性的能力）和成本是方案可行性的关键。`state_json`中储能成本为250万元/MWh，但未配置容量。
    3.  **并网与接入：** 如何将绿电（特别是自建部分）安全、可靠地接入数据中心配电系统，满足A级机房的高可靠性要求，需要详细设计。
*   **建议：** 必须优先完成能源系统方案的规划。建议采用“**自建分布式风电/光伏 + 锂电池储能 + 市电作为后备**”的混合模式。储能容量建议至少满足数据中心满载运行1-2小时（即500-1000kWh），以平滑绿电波动并作为应急电源的补充。具体规模需通过仿真优化确定。

## 4. 制冷系统与能效路径

*   **技术选择：** 项目已选定“浸没式液冷”，这是实现PUE 1.3目标的正确技术路径。相比传统风冷，浸没式液冷可以将冷却能耗降低50%以上。
*   **PUE目标可行性：** 在乌兰察布的气候条件下，结合浸没式液冷，PUE 1.3是一个保守且可实现的目标。通过优化液冷系统的二次侧（如采用干冷器进行全年自然冷却），PUE有望进一步降至1.2甚至更低。环境专家Wang的评估（PUE得分0.95）是合理的。
*   **数据缺失：** `state_json`中`cooling_result`为空，缺乏对冷却系统具体配置（如液冷机柜数量、CDU（冷量分配单元）配置、二次侧冷却方式）的仿真结果。这导致无法精确评估制冷系统的投资和能效表现。
*   **建议：** 应根据500kW负载和8kW/机柜的密度（约需63个机柜），完成浸没式液冷系统的详细设计。重点评估二次侧采用“干冷器 + 板式换热器”的全自然冷却方案，以最大化利用乌兰察布的低温优势。

## 5. 仿真结果解读与运行策略

*   **缺失项：** `power_supply_plan`, `green_power_result`, `cooling_result`均缺失，无法进行任何有效的系统仿真。
*   **运行策略建议：** 未来仿真应重点关注：
    1.  **绿电消纳策略：** 模拟在风光出力波动下，如何通过储能系统充放电和市电补充，在满足70%绿电比例目标的同时，最大化经济效益（如利用峰谷电价差套利）。
    2.  **制冷系统运行策略：** 模拟不同季节、不同负载率下，液冷系统的运行参数，验证PUE目标的可实现性。
    3.  **综合能源调度：** 将电源侧（市电、风光、储能）与负荷侧（IT负载、制冷负载）进行联动仿真，优化整体运行成本。

## 6. 财务可行性与投资回收

*   **核心矛盾：** 系统计算结果与专家意见存在显著分歧。
    *   **系统计算：** `economic_analysis_result`显示总投资为0，预算结余2000万。这显然是因为能源系统方案缺失，导致相关投资项（风电、光伏、储能）未纳入计算，**结论不可信**。

*   **关键指标分析（基于专家意见）：**

    *   **投资回收期：** 8年，偏长。对于数据中心行业，理想的回收期通常在3-5年。
    *   **ROI：** 12%，处于中等偏低水平。
*   **数据缺失与假设不一致：**
    1.  **IT负载假设不一致：** 项目规划为500kW，但经济专家假设为800kW（100个机架，8kW/机架），导致其成本估算基础与项目实际不符，需要重新计算。
    2.  **绿电成本缺失：** 专家意见未考虑绿电消纳（自建或外购）的成本，而这部分投资或运营费用对财务模型影响巨大。
    3.  **电价模型未利用：** `state_json`提供了详细的峰谷电价，但经济分析中未体现通过储能进行峰谷套利带来的收益优化。
*   **修正后的财务预测：** 假设项目采用“自建风光储”模式，初步估算：
    *   **IT设备及基础设施：** 约1000万元（63个机柜，含液冷系统）。
    *   **电力及绿电系统：** 约600万元（含小容量风电/光伏及储能）。
    *   **其他（土建、安装、设计等）：** 约200万元。
    *   **总投资估算：** 约1800万元。与专家估算接近。
    *   **年运营成本：** 考虑70%绿电后，年电费可大幅降低。利用储能进行峰谷套利，可进一步优化。

3.  组织所有专家（电力、经济、环境）基于统一的技术基线进行一次**联合评审**，弥合分歧，形成一致的可行性意见。
